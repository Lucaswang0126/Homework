# Homework

這個 Repository 用於存放課程相關作業與實作內容。

Repository 會依照不同的 **Lab / Homework** 進行分類，每一個作業會放置於獨立的資料夾中，方便管理、修改、查看以及使用 Git 進行版本控制。

---

## 📌 專案簡介

本專案主要用於整理課程中的各項作業與實作內容。

透過 **Git** 與 **GitHub** 進行版本控制，可以記錄每次作業的修改內容，並將完成的作業集中管理。

目前 Repository 已包含：

* Lab 3
* Git 版本控制設定
* 專案 README 文件

## 🎯 專案目的

本 Repository 的主要目的如下：

1. 整理課程中的各項作業。
2. 練習 Git 版本控制。
3. 熟悉 GitHub Repository 的使用方式。
4. 建立良好的專案目錄結構。
5. 記錄每次作業的修改與開發過程。

## 🌱 Git 版本控制

本專案使用 Git 進行版本控制。

基本 Git 操作流程：

```bash
git add .
git commit -m "Update homework"
git push
```

### 常用 Git 指令

查看目前 Repository 狀態：

```bash
git status
```

查看 Git Commit 紀錄：

```bash
git log
```

加入所有修改：

```bash
git add .
```

建立 Commit：

```bash
git commit -m "Update homework"
```

將本機修改推送至 GitHub：

```bash
git push
```

本 Repository 會透過 Git Commit 紀錄每次作業的修改。

## 📌 注意事項

1. 每個 Lab 建議使用獨立資料夾管理。
2. 不需要上傳的檔案應加入 `.gitignore`。
3. 每完成一個重要功能或作業階段，建議建立 Git Commit。
4. Commit Message 應盡量清楚描述此次修改內容。
5. README 文件會隨著 Repository 內容增加而持續更新。
